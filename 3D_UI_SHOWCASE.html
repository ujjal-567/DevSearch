3D UI Features

🎨 Advanced 3D UI

Modern, interactive, and immersive user experience

Glassmorphism Design
All major UI elements now use glassmorphic effects with backdrop blur, creating a modern frosted glass appearance. Elements have layered depth with semi-transparent backgrounds and subtle inner shadows.
background: rgba(248, 249, 250, 0.8);
backdrop-filter: blur(10px);
border: 2px solid rgba(66, 133, 244, 0.1);
3D Parallax Effects
Mouse movement triggers 3D rotation and tilt effects on cards. The closer your mouse, the stronger the 3D tilt and scale effects. Creates an immersive depth perception.
rotateX(${angleX}deg)
rotateY(${angleY}deg)
scale(${1 + proximity * 0.02})
Dynamic Adaptive Shadows
Shadow intensity and blur increase based on mouse proximity and hover state. Provides visual feedback and enhances the 3D layering effect. Shadows cast realistic light based on element depth.
box-shadow: 0 ${shadowStrength}px ${shadowStrength + 20}px rgba(...);
Floating & Float Animations
The main title has a subtle floating animation combined with background gradient shimmer. Creates continuous visual interest without being distracting.
@keyframes floatTitle {
  0% { transform: translateY(0px); }
  50% { transform: translateY(-10px); }
}
Advanced Gradient Backgrounds
Dynamic radial gradients animate in the background creating a breathing effect. Multi-color animated borders and text shadows enhance visual hierarchy and depth.
radial-gradient(circle at 20% 50%, rgba(...) 0%, transparent 50%)
animation: backgroundShift 15s ease-in-out infinite;
Interactive 3D Cards
Every card element (category, result, search box) responds to user interaction with:
  • 3D tilt on hover
  • Smooth scale transitions
  • Gradient background on hover
  • Enhanced shadow effects
  • Shimmer animation on interaction
Enhanced Microphone Button
The voice search button includes a pulsing glow effect when active. The red color with shadow animation provides clear visual feedback during voice recognition.
.voice-btn.listening {
  animation: pulse 1.5s infinite;
  box-shadow: 0 0 30px rgba(255, 107, 107, 0.8);
}
Scroll-based Parallax
Title moves slower than the scroll, creating a parallax depth effect. Combined with subtle rotation, it enhances the perception of depth as you scroll down the page.
title.style.transform = `translateY(${scrollTop * 0.5}px) rotateZ(...)`
Custom Easing Functions
All animations use cubic-bezier(0.34, 1.56, 0.64, 1) for bouncy, elastic transitions. Creates a more playful and modern feel compared to standard easing.
transition: all 0.4s cubic-bezier(0.34, 1.56, 0.64, 1);
