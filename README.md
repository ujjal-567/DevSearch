# SearchHub - Multi-Language Search Engine

## 📋 Overview
SearchHub is a fully-functional web-based search engine that indexes and searches documents in multiple languages: **HTML, CSS, JavaScript, and General Documentation**.

## 📁 Files Included

### HTML (index.html)
- **Home Page** - Google-style search interface with gradient logo
- **Search Results Page** - Pagination with 10 results per page
- **About Page** - Statistics and features overview
- **Advanced Search** - Multiple search options and filters
- **Settings Page** - Dark mode, history, preferences
- **Navigation** - Header with quick links

### CSS (style.css)
- Modern, clean design inspired by Google
- Dark mode support (toggle in settings)
- Responsive design for all devices
- Smooth animations and transitions
- Professional color scheme
- Component-based styling

### JavaScript (script.js)
- **48+ Sample Documents** indexed and searchable
- **Advanced Search Algorithm** with fuzzy matching
- **Intelligent Result Ranking** by relevance
- **Search History** stored in browser localStorage
- **Language Filtering** for specific document types
- **Pagination** support for large result sets

## 🔍 Search Features

### Basic Search
- Full-text search across all documents
- Real-time result display
- Relevance-based ranking
- Language filtering

### Fuzzy Matching Algorithm
- Handles typos and partial matches
- Substring matching
- Character sequence matching
- Multiple keyword support

### Advanced Search Options
- **Contains** - Find documents containing the phrase
- **Exact Match** - Find exact phrases only
- **Starts With** - Find documents starting with query
- **Ends With** - Find documents ending with query
- **Sort By** - Relevance, Date, or Content Length

### Smart Result Ranking
1. Exact title matches (highest priority)
2. Title keyword matches
3. Content keyword matches
4. Fuzzy matching scores
5. Relevance percentage display

## 🎯 How to Use

### Opening the Search Engine
1. Open `index.html` in any modern web browser
2. No server or installation required
3. Works offline after first load

### Basic Search
1. Type your search query in the search box
2. Press Enter or click the Search button
3. Results appear with relevance scores
4. Click any result title for full details

### Language Filtering
1. Check/uncheck language filters
2. Select: All, HTML, CSS, JavaScript, General
3. Results update automatically

### Advanced Search
1. Click "Advanced" in the navigation
2. Enter search terms
3. Select language, search type, and sort option
4. Click Search button

### Settings
1. Click "Settings" in the navigation
2. Enable/Disable Dark Mode
3. Enable/Disable Search History
4. View search history
5. Clear history or export data
